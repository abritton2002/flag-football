# Acosta Athletics & Training

Static landing page for Acosta Athletics & Training.

## Local Preview

Open `index.html` in a browser, or run a simple static server from this folder.

## Netlify

No build step is required.

- Build command: leave blank
- Publish directory: `.`

`netlify.toml` is already configured for this.
